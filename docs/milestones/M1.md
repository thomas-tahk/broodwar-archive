## How to try it
Preview on your Mac (exact commands in the PR). Two views:
1. **Real catalog** — `npm run build && npm run preview`, open http://localhost:4321/broodwar-archive/ → 2001 SKY OSL → the gap view.
2. **Test catalog** (fictional matches, to see what a filled match looks like) — `CATALOG_DIR=test/fixtures/catalog npm run build && npm run preview` → Fixture League 2000 → pick a match.

Watch for:
- The look (dark broadcast-console style, race colours, grade badges) — your call.
- Wording on the gap view and match pages.
- Footer "Help fill the gaps" and the gap view's "Know where a copy is? Add it".

## Decisions that need you (most important first)
1. **Grades.** OGN's original uploads (480p) graded B, provisional, from the survey; AI upscales left ungraded until someone compares them side by side. Say so only if you want a different rule.
2. **Dates and set order.** Where both OGN uploads agree with each other but not with Liquipedia, OGN wins (ro16-b-2, sf-1, third); each case is noted on the match. Say so only if you'd rather follow Liquipedia.
3. **The look.** Dark navy console, Barlow Condensed headings, mono data, race colours T blue / P yellow / Z red, grade colours A green → D orange, X red. Say so only if you want it changed.
4. **Gap threshold.** A game counts as a gap unless it has a copy graded A–C; ungraded copies count as gaps until graded. Say so only if you disagree.

Every other interpretation is in [`docs/questions/M1.md`](../questions/M1.md).
