**Fixed along the way:** prefilled links put values in the wrong form fields; the copy form's upload "Title" box would have been filled with the issue title and saved into the catalog; bot PRs re-wrapped the whole YAML file they touched (now byte-identical except the change); unfinished seasons had no "Add a missing match" link; an item could land in a different year on Home than on Find; the fix form counted games from 0 while the copy form counted from 1; stale e2e scripts; small phone tap targets.

**Known, not fixed:**
- If `gh workflow run` fails after the PR exists, the issue comment says the PR failed; the PR body says "CI was dispatched" before it is.
- The submit workflow puts its token in the push URL (`gh auth setup-git` would be cleaner).
- Find filters use replaceState: one Back leaves Find rather than undoing a filter.
- Dead "Year unknown" fallbacks (the schema requires a year); `mapName` helper duplicated; Find e2e never types in the text box.
- `docs/questions/M1.md` still names the old issue templates.

## Decisions that need you (most important first)
1. **Turn on one repo setting before you merge** — the needs-you item on the PR has the exact clicks. Without it, a submitted form can't become a PR.
2. **After the merge, file one test submission** and check a PR opens with a green check — the only part of the done-gate the preview can't run.
3. **Wording** — "The Brood War broadcast archive", "Help build the archive", "Find a game", "What's missing", "Help fill this", "Footage lost" (grade X), "Open the original". Say so only if any should change.
4. **KPGA 1st Tour tier = mid** is provisional. Say so only if you rank it differently.
